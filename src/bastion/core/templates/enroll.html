A passkey lets this device approve Bastion's actions with Face ID or Touch ID. The Mac checks every approval itself.

  1. On the Mac, run sudo bastion passkey enroll. It prints an 8-digit code.
  2. Enter the code here within 10 minutes and tap Create passkey.
  3. Tap the button a second time to open Face ID or Touch ID.
